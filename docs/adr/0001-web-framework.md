ADR - Web Framework

Decision:
We chose JavaScript with Node.js and Express for the backend and React for the frontend of our Equipment Checkout application.

Options Considered:
Node.js with Express and React
PHP with Laravel

Why We Chose It:
Our team has experience with JavaScript, Node.js, and React. These technologies allow us to build the frontend and backend using JavaScript. Express is lightweight and works well for creating APIs, while React allows us to build an interactive user interface.

What We Are Giving Up:
By choosing Express, we are giving up some built-in features offered by larger frameworks like Laravel. We will need to configure certain features and tools ourselves.

Team Competency:
Several team members already have experience with JavaScript, Node.js, and React, allowing the team to begin development quickly without a significant learning curve.
